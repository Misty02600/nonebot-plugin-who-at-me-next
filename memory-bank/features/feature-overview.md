# 功能总览

## 项目目标功能

`nonebot-plugin-who-at-me-next` 计划提供一个更可靠的“谁 @ 我 / 谁回复我”查询体验。

## 计划功能域

- 消息监听：后台监听群聊消息，识别 `@`、`@all` 和回复/引用事件。
- 结构化记录：保存足够的信息来重建查询摘要，而不是只保存字符串。
- 查询：用户查询最近谁触达了自己。
- 清除：用户清除自己的记录，管理员或超级用户清除全局记录。
- 过期清理：按配置清理旧记录。
- 输出渲染：优先稳定可读，必要时使用合并转发，失败时提供回退输出。

## 旧插件问题

- `Message` 被存入文本字段后，消息段语义容易丢失。
- 合并转发节点中的 `reply` 段在部分协议端或客户端无法稳定展示。
- `@` 段被改写成文本后，用户不一定能看出原始目标和语义。
- `@全体成员` 需要明确策略，避免尝试查询不存在的用户 `all`。
- 查询触发正则过宽，空命令前缀场景可能误触发。

# 命令行为

## 当前状态

当前源码仍是模板命令，尚未定义最终命令行为。

## 目标行为

后续命令应覆盖旧插件主要能力：

- 查询谁 `@` 了我或回复/引用了我。
- 清除当前用户在当前群的记录。
- 私聊或指定场景下查询/清除跨群记录，具体行为待设计确认。
- 超级用户清除全部记录。

## 命令设计原则

- 避免旧上游的宽泛 `on_regex(r"谁.*(@|艾特|圈|[aA][tT])+.?我")` 误触发问题。
- 对正式命令优先考虑精确命令或 `on_alconna`。
- 需要支持常见中文触发词，但要保证在 `COMMAND_START` 包含空字符串时仍可控。
- 清除类命令应比查询类命令更严格，避免误删。

## 待确认

- 查询命令是否继续支持无前缀自然语言，如 `谁艾特我`。
- 是否保留旧命令别名：`谁@我`、`谁at我`、`清除@`、`clear_at`。
- 私聊查询是显示所有群记录，还是需要显式参数选择群。
- 清除全部记录的权限和确认交互方式。

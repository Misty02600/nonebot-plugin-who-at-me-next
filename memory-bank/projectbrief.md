# 项目简介

## 概述

`nonebot-plugin-who-at-me-next` 是一个面向 NoneBot2 / OneBot v11 的群聊提醒记录插件，目标是在行为上继承 `nonebot-plugin-who-at-me` 的核心体验：记录群聊中谁 `@` 了用户、谁通过回复/引用触达了用户，并允许用户查询最近相关消息。

项目当前处于仓库初始化阶段，尚未实现业务功能。

## 核心要求

- 保持旧插件的主要用户行为：后台监听群消息，记录 `@我` 与回复/引用我的消息，用户可查询与清除记录。
- 修复旧插件在合并转发展示、回复消息展示、`@` 消息展示、`@全体成员`、数据持久化和协议端兼容上的已知问题。
- 代码结构要适合发布为独立插件，避免把 matcher、业务规则、持久化和渲染混在一个文件里。
- 面向 OneBot v11 优先设计，兼容 NapCat / Lagrange 等常见协议端的能力差异。

## 目标

- 发布一个可维护的 `nonebot-plugin-who-at-me` 替代版本。
- 提供稳定、可读的查询输出，不依赖协议端一定能在合并转发节点里正确渲染嵌套 `reply` 段。
- 将消息记录、查询筛选、输出渲染、存储迁移和命令入口拆成清晰边界。
- 从一开始保留可测试性，核心逻辑用纯单元测试覆盖，NoneBot 行为用 NoneBug 覆盖。

## 范围

### 范围内

- NoneBot2 插件仓库脚手架。
- Memory Bank 项目记忆初始化。
- 后续实现 `@` / 回复记录、查询、清除、过期清理、输出渲染和配置。
- 后续准备 PyPI / NoneBot Store 发布所需的元数据、README 和测试。

### 范围外

- 当前初始化阶段不实现业务功能。
- 当前阶段不迁移 `nonemigut` 里的本地旧数据。
- 当前阶段不承诺跨 OneBot v11 之外的适配器。
